Cyberpunk Conflict Studio - manager setup

Conflict Studio is a portable external tool. Keep the complete extracted package together.

Nexus package

Download the same ZIP manually for MO2 or Vortex. It contains one `ConflictStudio.exe` under Conflict Studio and the Vortex extension at the top level of the ZIP. The beta release is unsigned, so Windows may show its normal unknown-publisher warning on first launch.

MO2

1. Do not install the ZIP as an MO2 mod. Extract it anywhere outside the MO2 instance's `mods` directory. A folder such as `<MO2 instance>\tools\Conflict Studio` works.
2. Open Settings > Workarounds > Executables Blacklist and add ConflictStudio.exe. Conflict Studio needs to read the real profile and mod folders, without MO2's virtual file system combining them.
3. Open the executable list beside Run and choose Edit.
4. Add the extracted Conflict Studio\ConflictStudio.exe as a custom executable.
5. Set Start in to the MO2 instance root containing ModOrganizer.ini.
6. Use arguments: --manager mo2 --profile current
7. Leave Force load libraries and Create files in mod instead of overwrite unchecked.
8. Run Conflict Studio from MO2. On MO2's blacklist warning choose Continue; the tool does not need virtualized files. Use MO2's Shortcut menu if you want to pin it to the toolbar.

Conflict Studio updates the copy of archive\pc\mod\modlist.txt selected by your MO2 profile, in the mod folder or Overwrite folder that supplies it. If the profile has no selected order file, it creates one in MO2 Overwrite. MO2 may remain open. Cyberpunk must be closed. If the Cyberpunk MO2 plugin setting "enforce archive load order" is enabled, disable it before applying a custom order because MO2 will regenerate the file before launch.

Do not scan or change archive order in an MO2 profile while Vortex files are still deployed into the same Cyberpunk installation. Purge Vortex first or use Conflict Studio in Vortex mode. Files left by another manager can make the game folder differ from your selected profile, so Conflict Studio checks for them during scans and before saving changes.

Vortex

1. Download the Nexus ZIP manually. Open Extensions in advanced mode, drop the ZIP onto the extension install area, then restart Vortex.
2. Activate the Cyberpunk 2077 profile and deploy it.
3. Open Cyberpunk 2077 > Tools. The extension adds Conflict Studio automatically with the correct executable, working directory, and Vortex arguments.
4. Launch Conflict Studio from that Tools entry. Keep the extension enabled in Vortex. It tells Conflict Studio which profile is active, where the game and mod folders are, which mod supplies each installed file, whether deployment is up to date, and the archive order.

Keep Vortex running when saving archive order. The extension checks that the request matches your current profile and installed archives, backs up archive\pc\mod\modlist.txt in the game folder, writes the new order, checks the saved file, and updates the profile information sent to Conflict Studio. Vortex's Cyberpunk archive support reads that file. This does not change Vortex's separate REDmod order. Deploy any pending changes in Vortex before scanning or saving an order.

Manual installation

1. Extract the downloaded Nexus ZIP anywhere you prefer and run Conflict Studio\ConflictStudio.exe.
2. Choose Manual in the manager selector.
3. Browse to the Cyberpunk 2077 installation folder containing bin and archive.
4. Scan the deployed game. Archive order writes go directly to archive\pc\mod\modlist.txt with the same preview, backup, game-process guard, verification, and undo protections.

Manual mode also blocks scans and archive-order changes when files in the game folder exactly match copies listed in the saved Vortex profile information. This prevents mixing a Vortex-managed installation with another mode. Purge Vortex first or use that profile in Vortex mode.

Settings, saved reviews, scan results, logs, Vortex profile information, and support reports are stored outside the application folder. Updating or moving the published application does not remove them.
